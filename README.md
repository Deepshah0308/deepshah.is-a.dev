# deepshah.is-a.dev

Personal site of Deep Shah. React + Vite, Tailwind, Framer Motion, Three.js (react-three-fiber) and Lenis. Every push to `main` is built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

```sh
npm install
npm run dev    # local dev server
npm test       # script builder + token optimizer checks
npm run build  # static output in dist/
```
